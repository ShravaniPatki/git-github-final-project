# Simple Interest Calculator

## Project Name
Simple Interest Calculator

## Description
The Simple Interest Calculator is a simple Bash-based program that
calculates the simple interest using the principal amount, rate of
interest, and time period provided by the user.

## Formula

The simple interest is calculated using:

Simple Interest = (Principal × Rate × Time) / 100

Where:

- Principal (P) = Initial amount of money
- Rate (R) = Rate of interest per year
- Time (T) = Time period

## How It Works

The program asks the user to enter:

1. Principal amount
2. Rate of interest
3. Time period

It then calculates and displays the simple interest.

## Example

For:

- Principal = 10,000
- Rate = 5%
- Time = 2 years

The calculation is:

Simple Interest = (10000 × 5 × 2) / 100

Simple Interest = 1000

Therefore, the simple interest is *1000*.
